A tajweed revision quiz app for beginners. 
Right now, it's just catered to beginners, but hopefully with time I'll try and accomodate to more advanced students as well.

## Who is this for?
Anyone learning the basics of tajweed who wants to drill the rules quickly.

## Contributing
Make your own branch and open a PR.

To run locally:

```
cd frontend
npm install
npm run dev
```
